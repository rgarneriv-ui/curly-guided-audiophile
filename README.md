# curly-guided-audiophile

Record macOS system audio straight into Voice Memos while still hearing it.

See [`macos-audio-capture/`](macos-audio-capture/) — a self-inspecting setup
toolkit built around BlackHole 2ch and a Multi-Output Device.

```bash
cd macos-audio-capture
./inspect.sh   # read-only; start here
./setup.sh
```

Must be run on the Mac being configured.
